## UNS Survival Server (1.16.5)

**Requirements:** Java 17 (OpenJDK).

### Quick Setup

1.  **Download Core (Paper 1.16.5 - Build 794):**

    Run this to download and rename the jar:
    ```bash
    wget https://api.papermc.io/v2/projects/paper/versions/1.16.5/builds/794/downloads/paper-1.16.5-794.jar -O server.jar
    ```

3.  **Start Server:**
    ```bash
    chmod +x start.sh
    ./start.sh
    ```
